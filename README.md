# 💰 ExpenseIQ - Smart Money Tracker

A full stack expense tracker web application built with HTML, CSS, JavaScript and Python Flask.

## Features
- User Authentication (Login/Signup)
- Add, Delete Transactions
- Category-wise tracking (Food, Travel, Shopping, Salary)
- Real-time balance calculation
- Filter by category and type
- Search transactions
- Export to CSV
- Analytics dashboard
- REST API with Flask backend
- SQLite database

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: SQLite
- Version Control: Git & GitHub
